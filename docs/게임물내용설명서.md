## 2. 게임 개요

"새총의 신"은 화면을 드래그하여 새총을 조준하고, 하늘을 날아가는 새를 맞추는 캐주얼 아케이드 게임입니다. 레벨이 올라갈수록 더 빠르고 다양한 종류의 새가 등장하며, 각 새마다 고유한 비행 패턴을 가지고 있어 전략적인 조준이 필요합니다.

## 3. 게임 규칙

### 3.1 기본 조작
- **조준**: 화면을 터치한 후 드래그하여 새총의 발사 방향과 파워를 조절
- **발사**: 손을 떼면 돌이 발사됨
- **파워 게이지**: 드래그 거리에 비례하여 발사 세기가 결정되며, 새총 위에 반원형 게이지로 표시
- **궤적 미리보기**: 드래그 중 예상 궤적이 점선으로 표시

### 3.2 레벨 시스템
- Lv.1부터 시작하며 무한 레벨로 진행
- 각 레벨마다 목표 명중 수가 있음 (Lv.1: 6마리, Lv.2: 9마리, 이후 +3씩 증가)
- 목표 달성 시 레벨업 화면이 표시되며 다음 레벨로 진행

### 3.3 실패 조건
- 새가 화면을 통과하여 빠져나가면 하트(생명) 1개 소멸
- 하트는 총 3개이며, 모두 소진 시 게임오버
- 게임오버 시 광고 시청으로 이어하기 또는 처음부터 다시 시작 선택 가능

## 4. 등장 캐릭터 (새 종류)

| 새 | 등장 레벨 | 크기 | 속도 | 비행 패턴 |
|----|-----------|------|------|-----------|
| 참새 | Lv.1~ | 작음 | 느림 | 직선 비행 |
| 비둘기 | Lv.2~ | 중간 | 보통 | 소폭 지그재그 |
| 앵무새 | Lv.4~ | 중간 | 빠름 | 부드러운 파도형 위아래 |
| 부엉이 | Lv.6~ | 큼 | 빠름 | U자형 포물선 (상단→중간→상단) |
| 독수리 | Lv.8~ | 매우 큼 | 매우 빠름 | 대각선 급강하 (상단→지면) |

## 7. 화면 구성

### 7.1 메인 메뉴 화면
- 게임 타이틀 "새총의 신" 표시
- "게임 시작" 버튼
- 최고 기록 표시 (Lv.2 이상일 때)
- 배경에 새가 날아다니는 애니메이션
- 조작법 안내 텍스트: "드래그로 조준 / 손 떼면 발사"

### 7.2 인게임 화면
- 상단 HUD: 현재 레벨, 명중 수/목표 수, 하트(생명) 아이콘
- 하단: 새총 이미지 + 고무줄 + 장전된 돌
- 배경: 하늘 그라디언트, 산, 구름, 나무, 잔디 (자연 풍경)
- 새가 화면 좌우에서 등장하여 날아감

### 7.3 레벨업 화면
- "LEVEL UP!" 텍스트 애니메이션
- 다음 레벨 번호 및 목표 명중 수 표시
- "시작하기" 버튼

### 7.4 게임오버 화면
- "아쉽네요!" 텍스트
- 도달 레벨 및 이번 명중 수 표시
- "광고 보고 이어하기" 버튼 (전면 광고)
- "처음부터 다시" 버튼
